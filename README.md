Project name : Fit log

Short description :  Fitlog is a workout website that helps users explore exercises , create a workout plan and keep track of their workouts.

Technologies used :
1. Next.js
2. Tailwind CSS
3. React Icons 
4. JavaScript 
5. react-hot-toast

5 key features of the project:

1. Workout Library
2. Workout Sorting
3. My plan 
4. Saved Workouts
5. Responesive Design 


Getting Started
```bash
npm install
npm run dev
```
